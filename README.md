# CAASITEK Electronics Website

A mobile-first storefront starter for CAASITEK Electronics.

## Included
- Public storefront
- Product catalogue
- iPhone pricing structure supplied by the owner
- Admin dashboard UI
- Admin login email: isaacmwale3024@icloud.com
- WhatsApp ordering
- Trade-in, repairs, delivery and hire-purchase sections

## Important
This is a deployable front-end starter. The admin login shown in this version is a demo UI only; it is not a secure production authentication system. Before public launch, connect the login and product management to a real authentication/database provider (for example Supabase or Firebase) and configure the production domain.

## Run
Open `index.html` locally, or deploy the folder to a static host.
